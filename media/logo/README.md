# cim-compare logo

The cim-compare logo is the CIM Users Group disc, split down the middle: the grey half stands for the baseline model and the coloured half for the destination.

| File | Use |
|---|---|
| `cim-compare-logo.svg`, `cim-compare-logo-1200.png` | Logo and wordmark, for light backgrounds |
| `cim-compare-logo-dark.svg`, `cim-compare-logo-dark-1200.png` | Logo and wordmark, for dark backgrounds (also inlined in the report header from `src/main/resources/report/logo.svg`) |
| `cim-compare-mark.svg`, `cim-compare-mark-<size>.png` | The disc alone, for light backgrounds and icons (16 to 512 px) |
| `cim-compare-mark-dark.svg`, `cim-compare-mark-dark-512.png` | The disc alone, for dark backgrounds |
| `favicon.ico` | Browser icon (16, 32 and 48 px); a copy is at the repository root for the website |
| `cim-compare-social-1280x640.png` | GitHub social preview (Settings › Social preview) |

The wordmark is set in [Montserrat](https://github.com/JulietaUla/Montserrat) (SemiBold and Regular) and converted to outlines, so the SVGs need no fonts. Montserrat is licensed under the SIL Open Font License; see `Montserrat-OFL.txt`.
